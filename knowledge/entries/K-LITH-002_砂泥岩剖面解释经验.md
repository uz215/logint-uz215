# 砂泥岩剖面解释经验（K-LITH-002）

> 用户原话（2026-11-06）："砂泥岩剖面以伽玛为准确定泥质含量，密度的变化要看井径的变化，不真实的不能使用"；"同一砂岩层里……中间没有泥岩隔开，也没有小于截止值孔隙度的砂岩隔开，怎么看都应该合并成一个层"。

## 一、伽玛是砂泥岩剖面的第一判据

- **泥质含量以伽玛为准**（GR→VSH 走本井自适应分位/谷底分界 `GR_sand_max`，绝不取绝对值死线）。
- 砂/泥归属出现争议时，**回伽玛裁决**：GR 低于本井砂泥分界（砂岩群）的点不因其它曲线异常被判泥岩。
- 灰质/密度/中子只作辅助；单条辅助曲线不得推翻伽玛。

## 二、密度必须对照井径，失真密度不得作证据

- **扩径（CAL/BIT>1.20）点的 DEN 判据一律不作数**：must 跳过、core 不计分、deny 组不触发。
- 只作用于"低密度作证据"的岩性（泥岩/煤/碳质泥岩）；盐岩等低密度骨架岩性（盐段必然扩径溶解）与"高密度证据（DEN>）"型条件维持原口径——扩径只会让密度偏低失真，不会偏高。
- 典型误判形态（XIMENIA-5）：RHOB 1.6-2.0 + DT 150-170 + CNL 40-48 在井眼冲蚀段整段满足"煤三高两低"；密度降低不是泥质/煤的证据。
- CALR 缺测/无 CAL 或 BS 的井：视同在径（维持原口径，不擅改）。

## 三、井眼失真点的归位也按伽玛

煤/碳质泥岩降级与区域知识改判（"该区无煤/无碳质泥岩"）的**去向不能一律改归泥岩**：
- GR < `GR_sand_max`（砂岩群）→ 归 sandstone（上下皆砂岩的低伽玛失真点回砂体）；
- 否则 → shale。
- 依据：XIMENIA-5 515.5-516.1m / 679.8-680.4m GR 27-67（比上下砂岩还低、砂质含量高），改归泥岩与图面矛盾。

## 四、同一砂体内应并层

- 相邻层**同岩性（同一砂岩体）、无泥岩隔层、无低于孔隙度截止值的致密砂岩隔开** → 合并为一层，即使中间夹薄干层（OIL-DRY-OIL 应为一个油层）。
- 实现口径：砂泥岩剖面异结论薄层并入阈值 = 最小层厚 1.0m（其它剖面 0.6m）；并入油气层时仍受水铁证否决（Sw>0.85 或 RT<1.0 不得升级，R58b）。
- 0.6m 以下孤立层仍作采样噪声剔除，不作解释层。

## 五、F 判据（错误形态速查）

| 图面现象 | 检查项 |
| --- | --- |
| 薄泥岩夹在砂岩中、伽玛比邻点低 | 是否煤/碳质误判→区域知识改判残留；去向是否按伽玛 |
| 伽玛平直而出现泥岩段 | 是否仅凭密度降低（低密度 core 加分）；CALR 是否>1.20 |
| 同一砂体被切成多层 | 异结论薄层并入阈值；层间是否有真实隔层（泥岩/致密砂岩） |
