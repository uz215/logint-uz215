# 收录范围与合规准则（K-SYS-003）

## 一、定位

本知识库（logknow）是**以测井专业知识为主的油气知识库**。收录的唯一准绳是
「是否具备油气测井专业知识价值」，**按内容实质判定，不按文件名 / 文种 / 字样一刀切**。

## 二、可入档范围（正向清单）

1. **测井专业技术**：方法 / 仪器 / 采集 / 处理 / 解释 / 规范 / 专业软件。
2. **油气地质、录井、跨专业通用**：标准规范（仅跨专业）、课题项目管理、专业软件工具。
3. **测井类服务合同及技术附件（本条重点，可入档）**：
   - **研究的要求**：研究目标、技术路线、攻关方向、需解决的技术问题；
   - **采集服务的项目及要求**：测井项目、采集系列、施工与质量要求、精度指标、交付物；
   - **体现一定时期业主（甲方）的关注点和期望的结果**。
   - **价值定性**：这是**需求侧 / 期望侧的专业史料**——反映特定时期业主对测井采集与
     解释的技术关注点、质量门槛与预期成果，与方法侧的成果文档互补，具备
     **专业知识 + 史料**双重价值，应入档。
   - **归口**：按内容实质归「通用知识-项目管理」（课题设计 / 实施方案 / 研究报告小类），
     或按其中的技术内容归相应技术域；不因「合同」字样贬为行政杂项或排除。
4. **特定国家 / 地区合同的财税要求（v2 新增，可入档）**：
   - **地区特别税政策**：针对研究 / 采集服务在特定国家或地区开展业务的特别税制、
     税率 / 税种 / 关税 / 预提税 / 本地成分（Local Content）/ 外汇与汇兑等**区域性政策规则**；
   - **与之绑定的项目要求**：因税制 / 地区政策衍生的项目合规要求、资质、本地化比例、
     报关与结算规则等。
   - **价值定性**：这是**区域专属知识（国别知识）**——反映在某地区承接测井采集 / 研究
     服务所必须遵循的财税与合规环境，直接决定项目可行性与成本结构，属专业知识而非
     商务流水。**应入档**。
   - **归口**：`scope = 国别`（由 `detect_country` 从国家名派生）、`country` 标注具体国家；
     领域按内容实质归「通用知识」（区域规范 / 项目管理）或相应技术域。国别下钻按
     「国家 → 领域」组织（见 K-SYS-002）。

## 三、合规红线（排除 / 脱敏，负向清单）

需排除或在入档前脱敏的内容，均**与油气测井专业知识无关**：

- **个人隐私信息**：身份证号、私人手机 / 邮箱 / 住址、签字人个人身份信息、个人证件影像；
- **纯行政流程**：人事任免、考勤、内部行政通知流转、与专业无关的红头 / 会务材料；
- **交易性商务敏感（v2 精确化）**：单笔合同的**具体金额 / 报价 / 付款账户 / 实际纳税额 /
  银行与账号信息 / 发票流水 / 法律责任与争议条款 / 商业保密条款**。
  ⚠️ **「税务」不整体排除**：政策性 / 区域性的**特别税政策、税率税种规则、地区项目合规要求**
  属可入档的国别知识（见二.4），只排除针对具体交易的**金额与账户数字**。
  判别口径：**「规则 / 政策 / 要求」可入，「金额 / 账号 / 流水」排除**。
- **法律法规禁止**：国家秘密、涉密测绘等依法不得入库的内容。

处理原则：技术 / 政策内容与敏感条款**可分离**者 → 只入技术 / 政策部分或脱敏后入；
**无法分离且以敏感内容为主体**者 → 整篇不入库。

## 四、判定原则

- **按内容实质，不按字样**：「合同 / 招标 / 协议 / 要求」等字样本身不是排除理由；
  反之「研究报告」字样也不豁免隐私检查。
- **准入从宽、隐私从严**：技术 / 需求类内容尽量收录；个人敏感信息一项命中即须脱敏或排除。
- **不因题材联想误杀**：上一轮曾把「合同」整体列入「不引入的行政 / 人事 / 合同类」，
  本条正式校正 —— 测井类服务合同可入档（见二.3）；「税务 / 财税」同理不可整体排除，
  政策性税制可入档（见二.4）。
- **财税判别准绳**：「**规则 / 政策 / 要求**」可入（区域性、可复用知识），
  「**金额 / 账号 / 流水**」排除（单笔交易敏感数字）。区域性财税政策标 `scope=国别`。
- **排除需有证据**：判定排除应能指出具体敏感要素，不凭文件名猜测。
- **合规操作以只读抽查为主**：不自动删除数据，命中项人工复核后再处置。

## 五、合规抽查机制（配合持续入库）

- 每次报告重算随附生成 `output/收录合规报告.html`：正则只读扫描 `doc.title + meta_json`
  的身份证号 / 手机号 / 电子邮箱等个人敏感模式，列出命中项供人工复核。
- **基线（2026-11-13，扫描 4297 篇）**：身份证号 0 / 手机号 0 / 电子邮箱 5
  （5 项均为文献 DOI 或题名中的 `@` 误判，如 `10.1016@j.jappgeo...`，非个人隐私）
  → 当前库无个人敏感内容泄露。
- 抽查只读、不自动删改；命中需人工确认后再按第三节处置。
