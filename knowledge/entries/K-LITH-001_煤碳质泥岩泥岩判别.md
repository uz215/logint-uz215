# 煤 / 碳质泥岩 / 泥岩 判别知识（K-LITH-001）

> 本条目由多轮口述校正沉淀而来，**status=试行**：阈值是经验值，随新井复核持续校正（见校正历史）。

## 一、煤：三高两低 + 尖峰状突变

| 特征 | 曲线 | 典型表现 |
| --- | --- | --- |
| 高中子 | CNL/NPHI | 明显高（富含氢，40-60% 量级） |
| 高声波 | DT/AC | 明显高（疏松，>100 us/ft 量级） |
| 高电阻 | RT | **高尖**（电阻率突然升高） |
| 低密度 | DEN/RHOB | 明显低（1.2-1.8 g/cc 量级） |
| 低伽玛 | GR | **低值**（与泥岩/碳质泥岩的最强判别项） |

**关键约束：高低必须是尖峰状突变**（相对邻近围岩突然变化）——"没有这个一般都不是煤"。

## 二、碳质泥岩：与煤相似但不剧烈

特征方向与煤相同（密度偏低、声波/中子偏高、电阻率偏高），幅度是弱化版：密度一般 2.0-2.4，RT 相对泥岩较高但无突然高尖；**伽玛高**（与泥岩同侧，这是与煤的分水岭）。

## 三、程序判据落点（logInt.py，全部 deny 层/后置过滤）

| 知识点 | 判据 | 层级 |
| --- | --- | --- |
| 三高两低物理底线 | 煤 must：DEN<2.00 且 DT>100 | must |
| 高电阻高尖 | 煤 deny：RT<RT_coal_min(3×泥质基线) 且 CALR>1.20 → 非煤 | deny |
| 伽玛低值 | 煤 deny：GR≥GR_shale_min 且 DEN>1.85 → 非煤 | deny |
| 尖峰状突变 | `_demote_coal_without_spike`：段中位 vs 邻近围岩，煤需 DEN≤−0.12/DT≥+15/CNL≥+8/RT≥1.8× 任一，碳质减半；全不满足→泥岩 | 后置过滤 |
| 碳质泥岩伽玛高 | 碳质 must：GR>GR_shale_min | must |
| 碳质 RT 相对较高 | 碳质 deny：RT<RT_carb_min(1.2×泥质基线) → 普通泥岩 | deny |
| 密度不够轻 | 碳质 deny：DEN≥DEN_shale_light(泥岩P50−0.08) → 普通泥岩 | deny |
| 区域有/无 | info.json「区域知识」：标"无"→命中点改归泥岩（最强约束） | 后置过滤 |

## 四、反例（校正依据）

- **XIMENIA-5**（砂泥岩，无煤无碳质）：扩径坏井眼段密度低/声波中子大，形似煤但 RT 无高尖、GR 在泥岩区间、整段渐变无尖峰 → 三重排除（deny RT+井径 / deny GR+密度 / 尖峰过滤）。
- **BET-1**：真煤 GR 86-128、ρ1.45-1.65、CNL 40-54、Δt 122-127——伽玛低值与密度极低同时成立，判据不误杀。
