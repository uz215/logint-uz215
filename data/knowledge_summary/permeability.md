# 渗透率估算方法

分类: calculation

---


渗透率估算常用经验公式：

1. **Timur公式**：
   K = 0.136 * (φ^4.4 / Sw^2)
   适用于固结砂岩

2. **Coates公式**：
   K = (φ^3 * (1 - Sw)^2) / (Sw^2) * C
   其中C为常数，需根据岩心标定

3. **Wyllie-Rose公式**：
   K = (φ^2 * 10^8) / (τ^2)
   其中τ为迂曲度

4. **基于核磁共振**：
   K ∝ (T2gm * φ)^2 / T2lm
   其中T2gm为几何平均T2，T2lm为对数平均T2

渗透率估算受多种因素影响，需结合区域经验。
