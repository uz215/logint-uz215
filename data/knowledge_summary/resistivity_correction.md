# 电阻率校正方法

分类: correction

---


环境因素对电阻率的影响及校正：

1. **井眼校正**：
   - 井径扩大导致测量电阻率偏低
   - 校正公式：Rt_corrected = Rt_measured * (CAL / DH)^n
   其中DH为钻头直径，n为指数（通常取1.5-2.0）

2. **侵入校正**：
   - 泥浆滤液侵入形成侵入带
   - 深探测电阻率反映原状地层
   - 浅探测电阻率反映侵入带
   - 侵入半径可通过双侧向曲线计算

3. **温度校正**：
   - 电阻率随温度升高而降低
   - 校正公式：Rt(T) = Rt_measured * (T0 / T)^m
   其中T0为参考温度，m为温度系数

4. **泥浆电阻率校正**：
   - 泥浆电阻率随温度和盐度变化
   - 需根据实际测量值进行校正
