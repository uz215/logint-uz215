## 1. 逐点解释链（顺序即依赖）

```
岩性识别(LITHOLOGY) → POR 计算 → Sw 计算（Rw 优先级链）
→ 流体分类（逐点 INTERPRETATION）
→ enforce_fluid_segregation（重力分异整饰）
     ├─ 砂体一致性回填（R68，在流动单元划分之前）
     └─ 流动单元划分 → 气→油→水 单调叠置重整（R58）
→ apply_regional_no_water_veto（R59b 区域"无水层"否决）
→ 解释底界截断（R68，两个解释引擎共用后置块）
→ 按层聚合 _build_interpretation_layers → 层合并整饰
```

**位置敏感点**（实证教训）：
- 回填必须在 `enforce_fluid_segregation` 内**流动单元划分（segs）之前**，且回填后**重算 `is_res`**——否则回填点不进任何 seg，"水在油上"倒置无法被分异纠正（R68 fix3/fix4 实测）。
- 解释底界必须在两个解释引擎（高级/规则）汇合之后、按层聚合之前——单引擎分支内插入会漏掉另一引擎的井（R68 run2 实测）。

## 2. 砂体一致性回填（R68 用户定案）

**问题**：统一储层过滤（VSH>0.40 / POR<截止）把同一连续储层岩性体的中下部留空，流动单元被切成"顶部薄片+以下空白"，51 层出现"大砂层上部解释一个水层、下部空白"——用户："砂岩下部和上部没有隔层，那下部是啥……水不能在上部啊"。

**规则**：同一连续储层岩性体（`_NON_RESERVOIR_KEYWORDS` 排除法判定）内，已解释点给出结论，留空点按以下顺序归并：
1. **向上就近继承**（下方留空点取其上方最近已解释点结论——水不会倒置在油上）；
2. 体首解释点之上的空白 → 取其下方最近已解释点结论（对称分支）。

**闸门**（不满足则不回填）：
- 总孔隙度 **PHI≥0.06**——真致密才算隔段；有效孔隙度 POR 受泥质校正归零≠致密（13/14 间隔段 VSH 0.45-0.60、POR=0 但 PHI 0.19-0.24，正确合并）；
- 油气方向（GAS/OIL）过 R58 铁证否决：`Sw>0.85 或 RT<1.0` 的留空点不升级为油气。

**实测**（XIMENIA-5）：回填 229 点；13 层 625.0-647.4 合并为单一 OIL 22.4m；51 层体 1852.6-1865.8 单一 OIL 13.2m 无倒置。

## 4. 解释底界（R68 用户定案）

**问题**：XIMENIA-5 数据到 2849.5m 而 POR/Sw 有效止于 2827.8m，旧口径在 PHI=0 段仍按 Sw/RT 出 OIL/WATER 伪结论（2832-2840m OIL）。用户："2830 米以下没有有效曲线就别解释了"。

**规则**：`POR/PORD/POR_EFF` 有效值>0 **且** Sw 有限的最后索引 = 解释底界；以下 INTERPRETATION/ITP/SCORE/HIT_RATE 全清空。

**判据=列级择优（fix5）**：按优先级取**第一个"存在有效正值"的列**（POR → POR_EFF → PORD → PHI），**不做跨列并集**——深部 RHOB 死值使 PORD/PHI 饱和在 0.4 上限（XIMENIA-5 实测并集口径把底界拖到 2849.1m、4 点伪层），有效孔隙度 POR 才能测出真实底界。POR/POR_EFF 缺列时才回退 PORD/PHI。

**实测**：XIMENIA-5 底界 2827.8m、217 点留空；层表最深底 2807.1m，2828m 以下伪层全无。

## 5. 分异整饰与否决（R58/R58b/R59b）

- **enforce_fluid_segregation**：同一储层内逐点独立判定的油气水交错，按流动单元统一重整，自上而下 气→油→水 单调叠置。
- **升级否决（R58b）**：整饰中水→油气方向的升级必须过 `Sw>0.85 / RT<1.0` 铁证，否则不升级（防整饰造出无证据油气）。
- **区域无水否决（R59b）**：`<井名>info.json`「区域知识」`无水层=是` 时，WATER 点统一否决为 NonReservoir。
