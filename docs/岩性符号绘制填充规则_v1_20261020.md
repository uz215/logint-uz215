# 岩性符号绘制填充规则 v1（按 symbol/ 参考图为准）

**生效日期**：2026-10-20（同日三次定案：参考图化 → 行高统一 → 整图瓦片＋行高统一扩展）
**代码锚点**：`logvis.py`（`_SYMBOL_REF_IMAGE` / `_SYMBOL_REF_PITCH` / `_ref_row_phase` / `_lith_ink_tile` / `_lith_ref_pitch`）
**配套门禁**：`_test_symbol_consistency.py`（T1–T7）｜ **背景**：`_report_refink/_refall/_rowrule_20261020.md`

---

## 0. 总则（唯一原则）

**一切以 `F:/360/src/symbol/` 下的参考图为准——底色和纹理都以参考图为主。**

- 禁止矢量手绘模仿参考图符号——已证明（硬石膏人字）矢量法无解且每类都要花大精力；
- **瓦片 = 参考图整图不透明上墙**（三次定案）：底色、纹理全部来自参考图自身，**不再统一底色**；`LITH_BG_COLORS` 仅作瓦片加载失败时的兜底；
- **行高统一**：同一张图上每个符号的每行纹理高度一致（灰岩/白云岩/硬石膏等碳酸盐岩剖面统一为 9px/行）；
- 同一套规则同时驱动**实体岩性道、剖面道、图头图例**三处，禁止任何一处自行计算格距或另行绘制；
- 换参考图 / 新增岩性**不需要改绘制代码**（见 §7 操作规程）。

## 1. 机制总览（三层流水线）

1. 注册表查参考图：`_SYMBOL_REF_IMAGE`
2. 分类定格距：`_lith_ref_pitch`
3. 参考图整图瓦片：`_lith_ink_tile`
4. 平铺渲染：`draw_lithology_pattern`（实体）/ `draw_lithology_pattern_fig`（图例）

## 2. 规则一：参考图注册表

- 查表 `_SYMBOL_REF_IMAGE`：**中文名与英文名都注册**（如 `'dolomite'`/`'白云岩'` → `Dolomite.png`）；
- 未注册名字不进入参考图路径，走旧 kind 路由或"无符号"（`'none'`），**不得**落到别的岩性的符号上；
- 一类岩性只允许一个参考图文件（同义/近义岩性可共指同一文件，如 硬石膏=石膏 → Anhydrite.png）。

## 3. 规则二：符号三分类与格距（"每行纹理高度统一"）

格距统一由 `_lith_ref_pitch(ref_file)` 决定，**优先级：特例表 → 行数自动量测 → 回退 28px**。

| 类别 | 判定（看参考图） | 格距规则 | 现值 |
|---|---|---|---|
| **① 行状** | 参考图为 N 行重复离散符号（砖块 / 横线 / L括号 / 人字带） | 格距 = **N × 9px**（`LITH_REF_ROW_PX=9`，每行纹理高度统一 9px）。N 由 `_ref_row_phase` 从参考图**自动量测**（横向贯穿缝带中心差中位数优先，退化到墨迹行带起点差中位数），换图不改代码 | 白云岩 6行×9=**54**，灰岩/泥岩/盐岩 4行×9=**36**，硬石膏 2行×9=**18**（三次定案移入行状规则，与灰岩/白云岩每行高度统一） |
| **② 点状** | 点阵（砂岩） | 特例表锁定历史确认口径 | Sandstone=**40**（8行点×5px 点距） |
| **③ 块状** | 单个大 motif（倒L、V、圆砾、问号） | 特例表锁定用户确认"大小合适"的格距 | 玄武岩 28、火山岩 42、砾岩 32、未知 28 |

- 量测失败（零墨迹/无周期）回退 `_SYMBOL_PITCH['ref']=28`；
- 行数量测结果按文件缓存（`_REF_ROW_PHASE_CACHE`），进程内只量一次。

## 4. 规则三：整图瓦片生成（`_lith_ink_tile`，四步固定顺序）

对参考图执行，产出 **RGBA 不透明整图瓦片（底色+纹理以参考图为准）**：

1. **去贯穿框线**：以参考图众数色为自身底色；外圈 2px 墨迹率 >50% 视为参考图自带示意边框，用底色覆盖（防黑框上墙）；
2. **行相位对齐**：按量测出的首行相位 O 做纵向循环移位（`np.roll`，RGB 整体滚动），把首行 motif 顶到瓦片顶——否则跨岩性行线错开半行；
3. **LANCZOS 缩放**到 tpx×tpx（tpx=格子屏幕像素=格距，**实体与图例必须传同一 tpx**，保证两端逐像素同源）；
4. **不透明上墙**：alpha=1，保留参考图全部像素（底色+纹理不再分离）。

瓦片按 `(文件, tpx)` 缓存（`_lith_ink_tile_cache`）。

## 5. 规则四：底色以图为准（三次定案，废除统一底色）

- 瓦片整图不透明，参考图自身底色即成图底色（白云岩青底、玄武岩红底、硬石膏紫底…）；
- `LITH_BG_COLORS` 降级为**兜底**：仅瓦片加载失败时使用，不再是成图配色来源；
- 新岩性注册时无需强制补 `LITH_BG_COLORS`（可给兜底色）。

## 6. 规则五：排布与对齐（跨段跨岩性行线接续）

- **行相位对齐**：瓦片首行 motif 已顶到瓦片顶（§4 步 2）；
- **全局锚定**：实体道 ref 分支格网原点 `_org=0.0` 锚定**绝对深度 0**（不是段顶）→ 同道相邻段、相邻岩性的行线落在同一全局网格上，接续不断；
- 图例用 `BboxImage` 阵列，与实体同一瓦片、同一格距函数。

## 7. 规则六：参考图质量要求与废图特例

**可用参考图要求**：有可辨识纹理 motif；周期可量测或有明确特例格距；无棋盘格伪迹。

**特例处理**（按现状定案）：
| 情形 | 处理 | 实例 |
|---|---|---|
| 参考图纯色零纹理（整图同色） | 合法特例：**纯色填充**（整图上墙后即纯色），门禁 T7a/T7b 断言 | 煤（Coal.png 纯黑，用户定案"煤就是黑色没有煤横线"） |
| 参考图为棋盘格/噪点废图 | **禁用**，等用户换图；不得凑合用 | 黄铁矿 Pyrite.png |
| 墨迹与底色冲突（如黑底青线） | **禁用**，待用户确认 | 碳质泥岩 |

## 8. 规则七：新增/更换岩性符号操作规程（不改绘制代码）

1. 把参考图放入 `F:/360/src/symbol/`（PNG 优先，确认不是废图）；
2. 在 `_SYMBOL_REF_IMAGE` 注册（**中文名+英文名** → 文件名）；`LITH_BG_COLORS` 可选（兜底色）；
3. 仅当为**点状/块状**时，在 `_SYMBOL_REF_PITCH` 按用户确认的格距加一行特例；**行状符号什么都不用做**（行数自动量测，每行自动统一 9px）；
4. 跑门禁 `_test_symbol_consistency.py`（需 ALL PASS）→ 出图人工核对实体道/图例两端一致。

## 9. 规则八：门禁（`_test_symbol_consistency.py`，提交前必跑）

| 门 | 内容 |
|---|---|
| T1 | 全部注册岩性 kind='ref' 路由正确、瓦片可加载 |
| T5 | 矢量 kind 集合不被 ref 类污染（tokenize 剔字符串后断言） |
| T7a | 瓦片不变量：**不透明**（底色以图为准）、纹理占比合理（相对参考图自身底色）、零纹理特例（煤）frac==0、可按任意 tpx 缩放 |
| T7b | **实体 vs 图例 IoU ≥ 0.8**（剔 2px 边框防 spine 混入；墨迹量下限防"两端都空"假阳性） |

当前 38 名 IoU=1.00，ALL PASS；`_test_pattern_unify.py` 矢量回归同跑（头部屏蔽 ref 路由后全绿）。
