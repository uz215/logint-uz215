# 煤 / 碳质泥岩 / 泥岩 测井判别知识

> 来源：测井解释工程师口述知识，2026-10-28 定案。本知识是程序判据
> （logInt.py LITHOLOGY_RULES 煤/碳质泥岩规则）的依据，写入知识库作为
> 以后判别这三者的标准。

## 一、煤：三高两低 + 尖峰状突变

煤的测井响应特征是**三高两低**：

| 特征 | 曲线 | 典型表现 |
| --- | --- | --- |
| 高中子 | CNL/NPHI | 明显高（富含氢，可达 40-60%） |
| 高声波 | DT/AC | 明显高（疏松、孔隙极发育，>100 us/ft 量级） |
| 高电阻 | RT | 明显高，出现**高尖**（电阻率突然升高） |
| 低密度 | DEN/RHOB | 明显低（1.2-1.8 g/cc 量级） |
| 低伽玛 | GR | **低值**（煤骨架几乎不含放射性矿物） |

**关键约束：这些高与低必须是"尖峰状"的**——相对邻近围岩是**突然的
变化**（突变、成尖峰），不是渐变。没有尖峰状突变，一般都不是煤。

## 二、碳质泥岩：与煤相似但不剧烈

碳质泥岩特征方向与煤相同（密度偏低、声波/中子偏高、电阻率偏高），
但**幅度不如煤剧烈**，是弱化版。密度一般 2.0-2.4、声波/中子仅偏高、
电阻率相对泥岩较高但没有煤那样突然升高的高尖。

## 三、煤 vs 泥岩/碳质泥岩的最强判别项：伽玛低值

**煤伽玛低值**；泥岩与碳质泥岩伽玛高（泥质富含放射性矿物）。三者
之间用伽玛即可很好区分煤：伽玛落在泥岩区间（高于本井砂/泥分界）
的"低密度高声波"层不是煤，是泥质地层（多为坏井眼/扩径响应）。

## 四、程序判据落点（logInt.py）

| 知识点 | 判据落点 | 层级 |
| --- | --- | --- |
| 三高两低物理底线 | 煤 must：DEN<2.00 且 DT>100 | must（物理底线） |
| 高中子/低伽玛/低Pe 一致性 | 煤 core 加权项（CNL>35、GR<110、PE<2.2 等） | core |
| 高电阻高尖 | 煤 deny：RT<RT_coal_min（3×泥质基线）且扩径（CALR>1.20）→ 非煤 | deny |
| 伽玛低值判别 | 煤 deny：GR≥GR_shale_min（本井泥岩区间）且 DEN>1.85 → 非煤 | deny |
| 尖峰状突变 | 后置过滤 `_demote_coal_without_spike`：连续段段中位 vs 邻近围岩中位，煤需 DEN≤围岩−0.12 / DT≥围岩+15 / CNL≥围岩+8 / RT≥1.8×围岩 任一成立，否则改归泥岩；碳质泥岩阈值减半（−0.05/+6/+4/1.3×） | deny 式后置过滤 |
| 碳质泥岩伽玛高 | 碳质泥岩 must：GR>GR_shale_min | must |
| 碳质泥岩电阻率相对较高 | 碳质泥岩 deny：RT<RT_carb_min（1.2×泥质基线）→ 普通泥岩 | deny |
| 密度不够轻 | 碳质泥岩 deny：DEN≥DEN_shale_light（泥岩基线−0.08）→ 普通泥岩 | deny |

## 五、反例（教训）

- **XIMENIA-5（砂泥岩剖面，无煤无碳质泥岩）**：扩径坏井眼段密度读低、
  声波/中子增大，形似"两低两高"，但电阻率无高尖、伽玛在泥岩区间、
  且整段渐变无尖峰 → 三重排除（deny RT+井径 / deny GR+密度 / 尖峰
  过滤），全部改归泥岩。
- 判据演进遵守 deny 原则：排除性证据一律写 deny，must 只留物理底线；
  井级自适应阈值（RT_coal_min、GR_shale_min、DEN_shale_light 等）只放
  deny，避免"一会全有一会全无"的反复。
