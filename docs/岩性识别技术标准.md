## 2. 岩性分类体系（程序标准类别）

`sandstone`（砂岩，含砾岩/散沙并入）、`shale`（泥岩，含砂质泥岩/页岩）、
`coal`（煤）、`carbonaceous_shale`（碳质泥岩/页岩）、`limestone`（灰岩，含钙质泥岩薄层）、
`dolomite`（白云岩）、`anhydrite`（硬石膏）、`halite`（岩盐）、`basalt`（玄武岩等火成岩）。
归类规则：砾岩→砂岩、碳质页岩→碳质泥岩（`MERGE_LITH`）。

## 4. 识别方法（流程）

1. **数据准备**：LAS 载入 → 曲线名归一（`standardize_curve_names`：ZDEN/CNCF/DTC/RD/CALS 等 → 标准名）；
2. **数据清洗（§5）**：缺测标记、单位归一、非法值、深度去重排序（`logsys/clean.py`）；
3. **QC**：SY/T 5132-2012 曲线质量评价 + PE/中子专项 + 套管判定；清洗报告并入 QC；
4. **常规曲线岩性**：GR/VSH 判别砂泥岩；DEN-CNL 交会、PE 辅助碳酸盐岩/蒸发岩；DT 辅助；
   `classify_lithology` 多判据 + 元素/矿物反演（如有）；
5. **元素测井/矿物反演优先**：ECS 矿物体积按优势矿物定岩性（111D 真岩性库，`lith_validate` / `lithcal`）；
6. **区域约束**：按国家/地区允许类别过滤（§3）；
7. **层表聚合**：唯一点→层（薄层保护、族合并、复核标记；`logsys/layers.py`）；
8. **验证与回归**：`lith_validate`（层内多数票、宏 F1）、`lithcal`（点级 5 折）、黄金图/批量回归；
9. **改进闭环**：新资料→真值库→重标定→回归（长期）。

### 4.1 判据表（程序默认，分区域/分井可覆盖）

| 岩性 | 主要判据 |
|---|---|
| 砂岩 | 低 GR / 低 VSH；中子-密度交会落在砂岩骨架附近 |
| 泥岩 | 高 GR / 高 VSH；中子-密度交会泥岩区 |
| 煤 | 低 GR、低 RHOB、高中子（含氢高）、低 PE；`IS_COAL` |
| 碳质泥岩 | 高 GR、低密度、高电阻率；`IS_CARB_SHALE` |
| 灰岩 | 低 GR、低中子、高密度、PE≈5 |
| 白云岩 | PE≈3、密度较高 |
| 硬石膏 | 低 GR、高密度、低中子、PE≈5 |
| 岩盐 | 极低密度、高中子、PE≈4；`VOL_SALT` |
| 玄武岩 | 高密度、高中子/声波异常、PE 中高；`VOL_BASALT` |

## 5. 数据清洗与 QC 联动（程序：`logsys/clean.py` + `run_quality_control`）

- 清洗内容：缺测标记（≤-999 等）、单位归一（CAL/BS mm→in、NPHI 分数→百分、RHOB kg/m³→g/cc、DT us/m→us/ft）、
  非法值（GR 负值、RHOB/POR/RT/PERM 越界）、深度去重/排序/非正；
- QC 联动：清洗报告写入 `results['data_clean_report']` 并作为 QC 检查项 `data_cleaning`，
  导出 `<井>_data_clean_report.json` 与 `<井>_qc_report.json`；
- 要求：任何单位换算/数据删除必须在报告中可追溯（零静默修改）。

## 7. 质量要求与验收

- 岩性一致率（层内多数票）：≥90%（验收）；当前 Trakes 99.3%、111D 99.7%；
- 点级 5 折（诊断指标）：当前 Trakes 84.2%（受岩屑剖面薄互层限制）；
- 岩性剖面/真值库：Trakes 岩性解释剖面 240 层、111D ECS 矿物岩性 90 层；
- 任何岩性规则修改必须通过 `lith_validate`/`lithcal` 复验并记录来源与置信度。
