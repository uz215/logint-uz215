## 0. 三层原则（总纲，用户 2026-10-29 定案）

| 层 | 定位 | 取值规则 |
| --- | --- | --- |
| **must** | 物理底线 | **少而硬**，只放普适物理死值（骨架密度/声波窗口等不因井而异的量）；数目最少化，禁止放井级统计阈值 |
| **core** | 证据打分 | 阈值一律用**本井分位值 token**（`@token?fallback` 形式），**特别是伽马绝不用死值**；M-of-K 加权计分 |
| **deny** | 排除 | **物理死值可用**（允许多条件组合防误杀）；井级自适应 token 也放这里；**排除理由需证据**（如"扩径造成"必须带井径条件 CALR>1.20） |

配套铁律：
1. **剖面是整体**：剖面类型由 PTI（交会图+统计+矿物）综合判别，不是单点确定；
2. **每改判据必跑四井标定集回归**（见 §8）；
3. **排除性证据一律写 deny / 后置过滤**，不依赖任何门控开关的副作用；
4. 一切改判**留痕**（LITH_MC_WHY），可追溯。

## 1. 识别流水线（顺序即依赖）

```
Step 0  预检
  ├─ 套管段三重校验 → IS_CASING 掩码（套管段不参与岩性判别）
  ├─ 有效曲线统计（CAL/钻头不算、平直段不算；<3 条有效曲线不解释）
  ├─ PE 质量预检（不合格 → pe_reliable=False，PE 类判据自动跳过）
  └─ 中子质量预检（neutron_reliable）
Step 1  剖面类型判定 PTI（§2）；info.json「区域知识」剖面类型可覆盖
Step 2  自适应分位 token 计算（§3，按本井分布 + 特殊岩性剔除后统计）
Step 3  规则引擎逐点判别（§4 规则表 + §5 计分守门）
Step 4  兜底（§6）：无判据命中 → conf=0 默认泥岩；DEN>2.70 → 就近并入
Step 5  后置过滤链（§7，deny 式，全部留痕）：尖峰状 → 扩径 → 区域知识
Step 5b 留痕标注（R45 `_lith_why_post_annotate`，只改 WHY 不改岩性）：
        Q4 高密度泥岩(可能钙质) + Q5 火成岩界面 RT 抬升校验
Step 5c 迭代复核（R46 §9A `_iterative_lith_review`，二阶段）：
        少数派段参数对比→确认/否决降级/待目检 + 灰质含量 CALC_CONTENT
Step 6  输出：LITHOLOGY / LITHOLOGY_MC / CONF / WHY 四列同步
Step 7  交会图复核（§9：岩性面板全数据 + 稳健截轴；流体面板只储层）
```

## 2. 剖面类型判定（PTI，标准第 7 章 + 用户校准）

**电阻率是剖面判别的必要因子（R43 用户定案：光伽玛、中子、声波、密度还不够，还要有电阻）。**

**PTI = 加权综合指标，缺失项权重归一化（F_cluster 不参与）：**

| 分量 | 权重 | 内容 |
| --- | --- | --- |
| F_ecs | 0.30 | 元素/矿物体积（VOL_QUARTZ 等石英组 vs 方解石+白云石组 vs 蒸发岩组） |
| F_stat | 0.25 | 大段统计：P_den265（DEN>2.65 占比）、**P_rt100（RT>100 占比——电阻）**、**P_ac60**（DT>60 占比，用户校准"砂泥岩声波基本>60、碳酸盐<70"，替代标准 P_ac50——深部致密灰岩 DT 全>50 失去区分度） |
| F_cross | 0.20 | **密度-中子交会图碳酸盐区域占比**：CNL≤22% 且方解石线−0.05≤DEN≤方解石线+0.10（**R43 四井标定的非对称带**——原单侧 DEN≥线−0.05 把泥岩/含气砂岩点也划进碳酸盐区域，R-13 F_cross 曾达 0.82；实测分离：111D=0.59 / R-13=0.35 / XIMENIA=0.13 / BET-1=0.11） |
| F_morph | 0.15 | GR 形态：σ_GR 小/峰距小 → 碳酸盐（伽马值低起伏小）；σ 大/起伏大 → 砂泥岩（伽马高值高且多） |

判别（**R47 收窄**）：**PTI≥0.50 → carbonate；<0.42 → sand_shale；0.42-0.50 灰区 → core 判据组合井级占比裁决**（碳酸盐侧 CNL≤12%且DEN>2.62 vs 砂泥侧 CNL>20%且DT>62，取高者；区域知识仍优先覆盖）。
数据不足 → 自动回退旧法并留痕；**旧法回退判别同样含电阻率项**（RT P50：>50 偏碳酸盐 +1.0 分、<15 偏砂泥岩 +1.0 分，R43）。
特殊岩性（盐/膏/煤曲线判据命中点）与套管段先剔除再统计。
剖面类型影响：碳酸盐岩性（灰岩/白云岩）在 sand_shale 剖面下一致性项要求 need+1（守门）。

**曲线映射（R43，R65 收正）**：`DT` 族补 **DTTC**（纵波时差，R-13）；`RT` 族补 **RAL1-5**（阵列电阻率）、LLD/LLS/ILD；`CAL` 族补 CAL_AVERAGE；新增 `DTS` 族（**DTTST=横波**，用户定案，留作 Vp/Vs 岩性判别备用）。TG 与 GR 实测零相关（R-13），禁止映射到 GR。
**RT 取最深（R65 用户定案）**：RT 候选序一律**深→浅**排列（RT_LAS/RT/RD/LLD/ILD/RAL1→RAL5/AT90→AT10，浅探测 LLS/MSFL/RMSL 仅兜底）——RT 都是取最深那条电阻率曲线值。R43 旧序 MSFL/RAL5 在前是 R63 识别器误用 MSFL 的隐患源头，主流程经 R63 RT 回填绕过，R65 从候选序根治；实测 RASHIDPUR_13（RAL1 vs RAL5）与 BET-1/111D 逐点岩性 0 差异，TrakesKE-1（旧误用 MSFL P50=4.96 → 新 LLD P50=5.69）89 点按深探测证据改判（shale→sandstone 75 / shale→coal 9 / sandstone→shale 5）。注：HAL 阵列深探为 **RAL1**（实测油气段 RAL1 读数最高=探测最深，R-13；与 Sw 阶段 RESISTIVITY_CANDIDATES 的 RAL1 优先口径一致，旧文档"深探 RAL5 优先"系笔误纠正）。
**混合老井（R-13 型）**：全井 4233 点中现代九曲线仅覆盖约 500-643 点，老井段只有 TG——老井段曲线缺失点走兜底泥岩+conf=0 留痕，统计/PTI 仅用有效段。

## 3. 自适应分位 token 清单（core 用，绝不死值定界限）

| token | 定义 | 用途 |
| --- | --- | --- |
| `GR_sand_max` | GR 直方图双峰谷底；单峰回退 min(P25, P50×0.8) | 砂岩 must/core、泥岩 core |

**GR_sand_max 为什么是谷底而不是固定分位（R65 用户质询"伽玛应该是分位值"后取证定案）**：砂/泥 GR 分界对应的分位数**随各井砂泥比例漂移**，五口标定井谷底实测 XIMENIA-5=100.8(≈P63)/BET-1=134.4(≈P33)/RASHIDPUR_13=122.8(≈P93)/111D=80.2(≈P40)/SPS-108=91.9(≈P58)——不存在能同时逼近五井的固定分位，固定 P40/P50 会毁标定（如 RASHIDPUR_13 固定 P65=115 会把整个砂岩群划走）。谷底法本质就是"随井漂移的自适应分位"，每口井取值不同、绝无死值，符合"伽马绝不取绝对值"原则；单峰无谷时回退仍是分位（P25/P50）。
| `GR_shale_min` | =GR_sand_max（砂/泥 must 互斥） | 煤 deny、碳质泥岩 must |
| `GR_shale_soft` | 0.85×分界（软分界，模糊带交 core 裁决） | 泥岩 must、砂岩 deny |
| `GR_mud_strong` | 0.70×分界（强泥质门槛） | 砂岩 deny |
| `GR_lime_max` | GR P40 夹 [35,60] | 灰岩 core |
| `GR_dol_max` | GR P40 夹 [30,55] | 白云岩 core |
| `DEN_shale_lo` | DEN P75−0.15 夹 [2.40,2.60] | 泥岩 core 密度下限 |
| `DEN_shale_light` | DEN P50−0.08 | 碳质泥岩 deny（密度不够轻） |
| `RT_mud_max` | 裸眼段 RT P50，下限保护 3.0 | 砂岩 deny（泥质低阻） |
| `RT_mud_strong` | RT P40，下限保护 2.0 | 砂岩 deny（强泥质） |
| `RT_coal_min` | 3×泥质响应基线 | 煤 deny（无高尖+扩径才否决） |
| `RT_carb_min` | 1.2×泥质响应基线 | 碳质泥岩 deny（RT 无支持） |
| `GR_p10` | GR P10 夹 [20,80] | 砂岩 core 加分项 |

## 4. 岩性规则表（现值，priority 降序 = 判别优先序）

> 记法：`字段 比较值 (权重)`；`@x?y` = 分位 token，缺失回退 y。加粗的 = 待拍板项（§10）。

### 4.1 煤 coal（priority 100，score_min 6.0，core≥4）
- **must**：DEN<2.00；DT>100（物理底线：骨架极度疏松，普适死值）
- **core**：DEN<1.85(2.0)、DEN<1.70(1.0)、DT>115(1.5)、DT>105(1.0)、CNL>35(1.5)、CNL>28(0.8)、PE<2.2(1.5)、PE<1.6(0.8)、GR<@GR_coal_max?75(2.0)、GR<@GR_coal_max2?95(1.0)、RT>2.5(1.0)、CAL>8.6(0.5)
  - ※ 煤伽玛低值是最强判别项（R38 用户定案）。**Q1 已定案（R44，用户："煤的死值不对，也不会这么高，建议高值75，可以找分位里的低值"）**：`@GR_coal_max = clamp(本井 GR P10, 45, 75)`（分位低值+上限 75）、`@GR_coal_max2 = clamp(P10+20, 65, 95)`。BET-1 实测 P10=79.8→75 生效。注意：BET-1 强煤特征点（DEN<1.9&DT>100&CNL>30）GR 中位 122、P25=99——该井煤层伽玛并不低（有机质铀富集），GR 项拿 0 分后煤靠密度/声波/中子/PE 项判别（≥4 项仍可达 7.5 分），回归验证煤保留性
- **deny**：GR>150且DEN>1.80；GR>135且DEN>1.95；GR≥GR_shale_min且DEN>1.85；DEN>2.05；RT<RT_coal_min 且 **CALR>1.20**（R35：排除需井径证据）

### 4.2 黄铁矿 pyrite（92，4.0，core≥2）
- must：DEN>4.00；PE>6.00；core：CNL<8(1.0)、RT>3(1.0)、GR<90(0.5)

### 4.3 硬石膏 anhydrite（90，5.0，core≥3）
- must：DEN>2.83；DT<62；CNL<6；core：PE>4(1.0)、GR<40(1.5)、RT>10(1.5)、**DEN>2.92(3.5 决定性)**、DT<56(0.8)；deny：CNL>12；GR>85

### 4.4 碳质泥岩 carbonaceous_shale（90，6.0，core≥4）
- **must**：GR>@GR_shale_min?95（中高伽马=与煤的分水岭）
- **core**：DEN<2.45(2.0)、DEN≥1.95(1.5)、DEN<2.35(1.0)、GR>@GR_sand_max?115(2.0)、GR>135(1.0)、CNL>24(1.5)、CNL>28(0.8)、DT>88(1.5)、PE≥2.0(1.0)、PE<3.2(0.8)
- **deny**：GR<85且CNL>20；GR<75；DEN>2.46；DEN>2.42且CNL<26；DEN<1.90；PE>3.6；DEN≥DEN_shale_light（密度不明显低于本井泥岩基线）；RT<RT_carb_min

### 4.5 火成岩 igneous（86，5.0，core≥3）
- must：DEN>2.62；PE>4.00；CNL<8；core：DT<85(1.0)、RT>3(1.0)、DEN>2.75(1.0)、GR<120(0.5)
- **deny（R45 Q5 + R47 修订）**：CNL>18 且 GR>150（含氢高伽马绝不是火成岩）；**段级 deny（R47 用户口径"不是高密度、高电阻率的一定不是火成岩"）**——段内 RT 中位 < 上覆沉积岩×1.5（不高电阻）**或** 段内 DEN 中位 ≤ 上覆+0.03（不高密度）→ 整段并入上覆背景岩性众数并留痕（仅 igneous 规则标签；basalt 等元素锚段只留痕不改判）
- **界面电阻率抬升校验（R45 Q5/R47，`_lith_why_post_annotate` 三级校验）**：用户物理铁律——"火成岩一定是高密度、高电阻，比上部的沉积岩要明显的高得多，在沉积岩和火成岩界面上有明显的电阻率幅度的抬升"。实现：火成岩类段（igneous/basalt/tuff 等）段顶之上 300 深度单位沉积岩 RT 中位 vs 段内 RT 中位 + DEN 相对校验——①抬升 ≥2 倍且 DEN>上覆+0.03 → WHY 留痕"火成岩特征确认"；②电阻 <1.5 倍或密度不高 → deny 降级并入背景岩性（仅 igneous）；③其余留痕存疑并 warning。111D 实测：火成岩 RT 中位 142 vs 上覆 10.4 ≈ **13.7 倍**，DEN 2.75 vs 2.60，确认分支必命中、零回归。注意：111D 火成岩实际标签为 `basalt`（元素测井 VOL_BASALT 锚段+曲线扩展 `_basalt_context_ranges`），本规则表 igneous 服务于无元素道的井；deny 不另设 RT/DEN 绝对死值——井间尺度差异大，"明显高得多"用井内相对校验落实（Q5 定案）

### 4.6 岩盐 halite（84，5.0，core≥3）
- must：CNL<2.0（负~零中子=无氢铁证）；1.90≤DEN<2.35；DT<75
- core：CNL<−1(2.0)、DEN<2.15(2.0)、RT>5(1.5)、DT<70(1.0)、DEN≥1.95(1.0)、PE<5(0.5)
- deny：CNL>8；DEN>2.45；DT>85；GR>120

### 4.7 白云岩 dolomite（82，5.0，core≥3）
- must：DEN>2.74；DT<74；CNL<**14**（与 deny 对齐，R44）；core：**CNL<lin(3.0,2.5,14.0)（连续权重，R44）**、PE>3(0.8)、GR<@GR_dol_max?50(1.5)、RT>3(1.0)、DEN>2.82(1.0)；deny：CNL>14；GR>110

### 4.8 灰岩 limestone（80，5.0，core≥3）
- must：DEN>2.62；DT<85；CNL<**15**（与 deny>15 对齐，R44 消灭 12 分界线）
- core：**CNL<lin(4.0,2.5,15.0)（连续权重）**、PE>4.2(0.5 辅助)、GR<@GR_lime_max?55(1.5)、RT>3(1.0)、DEN>2.70(1.0)、**DT<72(1.0)**；deny：CNL>15；GR>110
- ※ **Q2 已定案（R44，用户："8-12 没有本质区别，在现实中都是灰岩，就是泥质含量的高低区别，改为连续权重，消灭分界线"）**：连续权重 `<lin` 语义 = CNL≤x_full 拿满 w_full、x_full→x_zero 线性衰减到 0。灰岩 (4.0, 2.5, 15.0)：CNL 4→2.5、8→1.59、12→0.68、15→0；白云岩 (3.0, 2.5, 14.0)。引擎 core 打分新增 '<lin' 项类型（命中即计 1 项 core 数，权重按线性值累加）

### 4.9 砂岩 sandstone（45，4.0，core≥3）
- **must**：GR<@GR_sand_max?105（低伽马=第一判别项，分位自适应）
- core：GR<GR_sand_max(2.0)、GR<GR_p10(1.0)、CNL<26(1.5)、DEN>2.10(1.0)、DEN<2.62(1.0)、DT<100(1.0)、PE<3.6(0.5)
- deny：DEN<2.05；**DEN>2.65 一票否决**（石英骨架极限，重晶石校正后物理无例外）；GR>GR_shale_soft且RT<RT_mud_max且DT>80；GR>GR_mud_strong且RT<RT_mud_strong且DT>85

### 4.10 泥岩 shale（10，2.0，core≥2，兜底岩性）
- **must**：GR>@GR_shale_soft?95（软分界，模糊带交 core 裁决）
- core：DEN>@DEN_shale_lo?2.40(1.5)、DT>@DT_shale_hi?85(1.0)、CNL>@CNL_shale_hi?20(1.0)、GR>@GR_sand_max?120(1.0)
  - ※ **Q3 已定案（R44，用户："分位化，但不是最低声波时差，也不是最低中子，应该是高中子"）**：泥岩=高中子高声波，token 取**高口径**——`@DT_shale_hi = clamp(DT P60, 70, 100)`、`@CNL_shale_hi = clamp(CNL P60, 15, 35)`。BET-1 实测 DT P60=89.6、CNL P60=24.9（贴泥岩响应；高于旧死值 85/20，更贴本井）
- **deny（物理死值，R42 用户定案）**：
  - ① `DEN>2.70 且 DT<60`（用户："密度2.70以上、声波60以下——这是什么泥岩"；双条件只排致密碳酸盐/蒸发岩，不伤高伽马致密泥岩）
  - ② `DEN>2.68 且 PE>4.5`（标准 12.3.1 [DH]，PE 不合格自动跳过）

## 5. 计分与守门

1. **must 全过** 且 **deny 全不过** 才进入计分（任一不过 = 该岩性出局）；
2. core 加权总分 ≥ score_min **且** 命中项数 ≥ core_min 才算命中；
3. 多规则命中时取 **priority 最高**者；
4. **剖面守门**：灰岩/白云岩在 sand_shale 剖面下一致性项要求 +1（need+1）；
5. 识别结果同步写 `LITHOLOGY`/`LITHOLOGY_MC`/`LITH_MC_CONF`/`LITH_MC_WHY`（WHY 记录命中规则，可追溯）。

---

## 6. 兜底（剖面是整体，无判据命中≠泥岩）

1. 无任何规则命中 → **conf=0 默认泥岩**（历史行为）；
2. **例外**：默认泥岩且 **DEN>2.70** → **就近并入邻段非泥岩已定岩性**（归并目标排除 shale——R42 教训：膏质过渡点规则命中泥岩作种子会把整段高密度点拽回泥岩），WHY 留痕"就近并入"；
3. 兜底点不计入置信统计，解释阶段按非证据点处理。

## 7. 后置过滤链（deny 式，顺序固定，全部留痕）

## 9A. 迭代复核（岩性识别二阶段，R46 用户定案）

> 用户原话："不能一次定……定完后要再去比较是不是参数上有明显区别，如果有确定是，
> 最优化算法的矿物成分就应该加进去灰岩，算出灰质含量……整个的岩性识别的迭代过程
> 应该写进程序，增加泛化能力。" 地质依据：煤/碳质泥岩是泻湖等环境生成，与砂泥岩
> 河流相的过渡区中间地带能生成灰质岩性——**砂泥岩剖面可以出现很少的灰岩/灰质泥岩，
> 但判完后必须回检参数，确认了才联动矿物反演**。

**Step A 少数派段提取**（`_iterative_lith_review`）：
- 背景岩性集按剖面：sand_shale={shale, sandstone, coal, carbonaceous_shale}；carbonate={limestone, dolomite, shale, halite, anhydrite}；
- 少数派 = LITHOLOGY_MC 中不属于背景集的岩性（如 sand_shale 剖面里的 limestone/dolomite），连续段 ≥3 点，且该岩性全井占比 <10%（占比过半的本来就主导剖面）；
- 四井实测：XIMENIA/R-13 无少数派（复核不触发）；BET-1 恰 1 段（8980-8984ft 钙质胶结 19 点）；111D carbonate 剖面少数派只留痕不降级。

**Step B 参数对比复核**（段中位 vs 段上下各 30 点背景岩性中位；证据计分制——普通差别 1 分、强差别 2 分）：

| 参数 | 普通差别(1分) | 强差别(2分) | 说明 |
| --- | --- | --- | --- |
| DEN | \|Δ\|≥0.08 | ≥0.15 | 钙质胶结最灵敏（BET-1 实测 Δ0.24=强） |
| DT | \|Δ\|≥8 | ≥15 | |
| CNL | \|Δ\|≥4 | ≥8 | |
| GR | \|Δ\|≥30 | ≥60 | |
| RT | 比≥2 或 ≤0.5 | 比≥4 或 ≤0.25 | |
| PE | \|Δ\|≥1.0 | ≥2.0 | 方解石 PE 5.08 vs 石英 1.81 |

- 段内与围岩都缺测的参数不计入（BET-1 段 GR/CNL 缺测 → 可比参数仅 4 项——**证据计分制避免"凑不满 3 项"误杀真钙质段**）。

**Step C 判定（总分 = Σ强2+普通1）**：
- **≥3 分 → 确认**：WHY 留痕"少数派岩性参数对比确认(x分)"，进入 Step D；
- **≤1 分 → 否决降级**（响应与围岩无差别，判据不可信）：sand_shale 剖面按 GR 回背景——段 GR 中位 ≥ 围岩 GR 中位 → shale，否则 sandstone（GR 缺 → shale）；留痕"少数派岩性参数对比否决降级"；carbonate 剖面本轮不降级仅留痕；
- **=2 分 → 保留原判 + 留痕"待目检"**（BET-1 19 点段：DEN 强 2 分、RT 比 1.57/PE Δ0.15 不计分 → 2 分待目检，零回归）。

**Step D 灰质含量联动（确认与待目检的灰岩/白云岩段）**：
- **有元素道**（111D）：optimize_minerals 全集矿物已含 Calcite，复核确认即视为该段方解石组分解锁，VCalcite 即灰质含量，留痕即可；
- **无元素道**（BET-1）：段级石英/方解石/水三组分**解析解混**（DEN+PE+物质守恒三方程；VSH 先扣除泥质：DEN_eff=DEN−2.55·Vsh、PE_eff=PE−3.45·Vsh），输出 **CALC_CONTENT** 列（逐点 0-1）；DT 作独立校验（|DT实−DT预测|>10 留痕告警"可能含泥/压实效应"）。
- BET-1 实测：该段灰质 0.15→0.55 向底部递增（中位 0.24，PE 2.36→3.62 同步抬升），φ→0 的钙质胶结致密化图景自洽。

**与既有机制的关系**：本复核在 `_lith_why_post_annotate`（R45）之后执行；只改 WHY/降级少数派/新增 CALC_CONTENT，不动主判据、不动 PTI——迭代是**外环**，规则引擎仍是**内环**，防止"迭代改判据"造成判据反复（deny 原则不破）。
